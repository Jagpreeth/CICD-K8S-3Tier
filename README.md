# CICD-K8S-3Tier
A three tier application for integrating CI/CD pipeline in an Nginx app featuring Docker build &amp; push, Kubernetes deployment, Rolling update and Blue-Green deployment

Goal: Automate the build, test, and deployment of a web application to Kubernetes with CI/CD.

Components:

App: Nginx webapp

Version Control: GitHub repository

CI/CD: Jenkins pipeline

Docker: Build & push images to DockerHub

Kubernetes: Deployment, Service, Ingress

Deployment Strategy: Rolling Update and Blue-Green
